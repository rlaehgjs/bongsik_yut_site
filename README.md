# 봉식이 생존 윷놀이 배치 분석기

## 실행
가장 간단한 방법:
1. 이 폴더에서 터미널/명령 프롬프트를 엽니다.
2. `python -m http.server 8000`
3. 브라우저에서 `http://localhost:8000`

`index.html`을 직접 더블클릭해도 대부분 동작합니다.

## 구현 규칙
- 경로: 출발 → 1 → 2 → 3 → 4 → 5 → 반환점 → 5 → 4 → 3 → 2 → 1 → 출발
- 출발점 도달/초과 즉시 종료
- 도/개/걸/윷/모: 1/2/3/4/5칸, 확률 25/37.5/25/6.25/6.25%
- 모 1회당 최종 배수 +1
- 점수말 3/2/1점을 서로 다른 3칸에 배치
- 모든 말 제거 시 즉시 0점 종료
- 배수: 1~3회 x1, 4~5 x2, 6~7 x3, 8~9 x5, 10회+ x10
- 20점 초과 결과도 최상위(20+) 보상으로 분류
- 상품가치는 화면에서 수정 후 재계산 가능

- 정렬 기준에 2등만(16~19점), 3등만(13~15점) 확률 추가

- v3: 2등만/3등만 선택 시 undefined/NaN이 나오지 않도록 지표 접근을 보강하고 JS/CSS 캐시 무효화 쿼리를 추가했습니다.

- v4 검색 형식 추가
  - `10230` = 1점 / 빈칸 / 2점 / 3점 / 빈칸
  - `1x23x` = 위와 동일 (`x` = 빈칸)
  - `1-23-`, `1·23·`, `1_23_`도 빈칸 표기로 사용 가능
  - 기존 쉼표 입력도 지원
